To  execute the files proceed in the follwoing manner:-
(1) First we create the table using the countries.csv file where one row is serial number, second is country names and third their respective codes.
(2) Install all npm packages required using the command npm i.
(3) In the index.js, make changes to the code by replacing your postgres password and database name.
(4) Run node index.js or nodemon index.js
(5) Go to the webpage "http://localhost:3000/"
(6) Enter the name of the countries you visited. It will change the colors of the countries you entered that you visited.
